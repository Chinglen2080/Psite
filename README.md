# Pradhya’s site

A scrapbook-style personal site built with React, Vite, TypeScript, and Tailwind CSS v4.

## Development

The Vite development server is managed by the project environment. For a local server, run:

```bash
pnpm install
pnpm dev
```

The optional in-browser profile editor is disabled by default. Set `PROFILE_EDITOR_ENABLED` to `true` in `src/App.tsx` to show it.

## Formatting

```bash
pnpm format
```
